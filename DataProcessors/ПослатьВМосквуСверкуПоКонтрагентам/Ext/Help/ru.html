Выполнение обмена.

Для правильного определения контрагентов при получении БАНКОВСКИХ платежей в Москве необходимо иметь полный список покупателей

и их договоров. Обработка позволяет пересылать данные в Москву для сверки и обновления.

Обмен может осуществляться  в двух режимах :

 - по протоколу FTP:

 - письмом через электронную почту.
