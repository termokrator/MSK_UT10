Обработка предназначена для создания документов "Реализация товаров (услуг)" для тех заказов, где предусмотрена НАША ДОСТАВКА (или доставка транспортной компанией)

 Для выбранных контрагентов, (при включенном флажке "отметка") по КАЖДОМУ договору контрагента создается и проводиться  документ "Реализация товаров (услуг)".  В бухгалтерию по электронной почте отправляется заявка на подготовку комплекта документов для водителя. 

Принудительно печатается форма заявки для склада, которую надо передать на склад.
