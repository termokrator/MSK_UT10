«Отчет по остаткам ТОХ»


Отчет формируется по товарам, по которым были поступления ТОХ

Остатки берутся на дату последнего выкупа по поставщику, который соответствует товару.

При этом поиск выкупа ограничен сверху полем ДатаПо и отбором Статус не равен “Возврат по браку”

В столбцах представлены данные:

По 5 регистрам:

  • Склад остаток
  • МТ остаток
  • ТОХ остаток
  • ТОХ Переданные остаток
  • ТОХ Поставщиков остаток

По метрикам ТОХ №1-3 и 5:

Метрика 1 = "Товары организаций (МТ)"

Нормальные значения: ≥ 0

Метрика 2 = "Товары на складах" - "Товары организаций (МТ)" – "ТОХ поставщика" + "ТОХ переданные в филиал"

Нормальные значения: 0

Метрика 3 = "ТОХ поставщика” – "ТОХ"

Нормальные значения: 0

Метрика 5 = "ТОХ" – "ТОХ переданные в филиал"

Нормальные значения: ≥ 0
