Настройка обмена.

Для задания настроек обмена используется справочник «Настройки обмена с порталом».

Для настройки транспорта обмена необходимо зайти в предопределенный элемент Москворечье.

В настройках указывается:

В разделе формирования заказов:

Организация – организация по которой будут создаваться документы в системе при загрузке с портала.

Папка для новых покупателей – группа справочника «Контрагенты» в которой будут создаваться новые контрагенты.

Склад портала – склад, который будет использован в документах загруженных с портала (заказ покупателя, заказ поставщику).

Валюта покупки – валюта в какой приходят цены покупателя. Если стоит валюта отличная от руб., возможен пересчет в рубли с коэффициентом (курсом). (На текущий момент принято решение что с портала будут приходить цены в рублях).

В разделе транспорт:

Ftp адрес обмена – адрес ftp сервера.

Порт FTP соединения – порт сервера ftp (по умолчанию используется 21).

Пользователь ftp соединения – имя пользователя для доступа по ftp.

Пароль ftp соединения – пароль пользователя.

В разделе дополнительно:

Сохранять файлы обмена – в системе 1с файлы загруженные с портала и выгруженные на него сохраняются в системе. (Первоначально включено для отслеживания ошибок, в дальнейшем можно отключить).

Сохранять протокол обмена – сохранение в системе протокола каждого обмена. (Для отслеживания сосотяния обмена).
