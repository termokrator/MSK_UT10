Каждое уведомление связывается с определенным событием. В уведомлениях указывается, кому именно и в каком виде будут отправлены сообщения при наступлении событий.

В уведомлении указывается перечень адресатов.

Это могут быть:

  • Пользователи
  • Партнеры (контрагенты)
  • Адреса электронной почты

  • Динамически выбираемые адресаты

В уведомлении настраивается вариант отправки писем.

 

Возможен один из трех вариантов отправки:

  • Общее для всех сообщение
  • Скрытые копии

  • Свой текст каждому

В уведомлении определяются шаблоны темы и текста отправляемого по электронной почте сообщения. В шаблон можно подставлять доступные поля источника события, которые при формировании сообщений будут заменены значениями.

 

Есть  возможность вставлять в текст сообщения таблицы. Настройка содержимого таблиц представляет собой определение структуры компоновки данных, связанной с источником события.

 

Текст сообщения может быть форматированным HTML, а также «простым текстом». Таблицы используются только в HTML сообщениях.
